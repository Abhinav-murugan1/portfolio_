# Jayasankar R Portfolio

A clean dark portfolio for Jayasankar R, focused on full-stack software, cloud-native delivery, and embedded systems work.

## Features

- Dark responsive design
- Animated canvas signal background
- Resume download links for software and embedded roles
- Experience, skills, projects, education, and contact sections
- Local GoFarm project preview asset

## Setup

Open `index.html` in a web browser, or run a local development server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Content

Edit `index.html` to update personal details, experience, projects, contact links, or resume paths.

## Styling and Motion

Modify `styles.css` for visual design changes. The animated canvas background and section reveal behavior live in `script.js`.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API
